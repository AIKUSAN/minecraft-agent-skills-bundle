# Quest Server Example Scenarios

Reference scenarios from a real quest server. They need that server's world and NPCs, so treat them as patterns to
copy, not as ready-to-run tests. The walkthrough is in `references/quest-server-example.md` in the skill folder.

Shared code comes from `../../java/` (`lib.js`, `dialogue.js`, `strategies.js`). Output goes to `QA_OUT_DIR`.
